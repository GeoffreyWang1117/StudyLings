# 算法复杂度速查表

快速参考常见算法和数据结构的时间/空间复杂度。

## 📊 Big-O 复杂度对比

从快到慢排序：

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

### 直观理解

| 复杂度 | n=10 | n=100 | n=1000 | 名称 |
|--------|------|-------|--------|------|
| O(1) | 1 | 1 | 1 | 常数 |
| O(log n) | 3 | 7 | 10 | 对数 |
| O(n) | 10 | 100 | 1000 | 线性 |
| O(n log n) | 30 | 700 | 10000 | 线性对数 |
| O(n²) | 100 | 10000 | 1000000 | 平方 |
| O(2ⁿ) | 1024 | 1.27e30 | - | 指数 |
| O(n!) | 3628800 | - | - | 阶乘 |

## 🎯 实用技巧

### 识别时间复杂度的模式

**O(1) - 常数时间**
```cpp
int x = arr[5];        // 直接访问
return a + b;          // 简单运算
```

**O(log n) - 对数时间**
```cpp
while (n > 0) {
    n /= 2;            // 二分、每次减半
}
```

**O(n) - 线性时间**
```cpp
for (int i = 0; i < n; i++) {
    // 单层循环
}
```

**O(n log n) - 线性对数**
```cpp
// 归并排序、快速排序
// 每层O(n)，深度log n
```

**O(n²) - 平方时间**
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // 嵌套循环
    }
}
```

**O(2ⁿ) - 指数时间**
```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // 朴素递归
}
```

### 空间复杂度优化技巧

1. **滚动数组**: DP 问题只需要前一行/前几行
2. **原地算法**: 不使用额外数组
3. **迭代代替递归**: 避免递归调用栈

### 选择合适的数据结构

| 需求 | 推荐数据结构 |
|------|-------------|
| 快速随机访问 | 数组/Vector |
| 频繁插入删除 | 链表 |
| LIFO (后进先出) | 栈 |
| FIFO (先进先出) | 队列 |
| 快速查找 | 哈希表/BST |
| 有序数据 | 平衡树/堆 |
| 范围查询 | 线段树/树状数组 |
