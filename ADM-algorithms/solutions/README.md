# 参考解答

⚠️ **重要提示**：请在完成练习后再查看解答！

这个目录包含所有练习的参考解答。这些解答：

- ✅ 都通过了所有测试
- 📝 包含详细的注释说明
- 🎯 注重代码可读性和正确性

## 使用建议

1. **先尝试自己解决**：独立思考是学习的关键
2. **卡住时查看提示**：使用 `adm-judge hint <name>`
3. **实在不会再看解答**：理解解答的思路
4. **尝试优化**：看能否想出更好的方法

## 学习建议

看解答时，重点关注：

1. **算法思路**：为什么这样做？
2. **数据结构选择**：为什么用这个数据结构？
3. **边界处理**：如何处理特殊情况？
4. **优化技巧**：有哪些优化空间？
