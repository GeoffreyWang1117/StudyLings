# Exercise 3: 内存段和栈帧布局

## 学习目标

- 理解程序的内存段布局（代码段、数据段、BSS、堆、栈）
- 掌握栈的增长方向
- 学习栈帧的结构
- 理解局部变量、参数、返回地址在栈中的位置
- 使用调试器查看内存映射

## 背景知识

### 程序内存布局

```
高地址
┌─────────────────────┐
│   命令行参数/环境变量   │
├─────────────────────┤
│   栈 (Stack) ↓      │  局部变量、函数参数、返回地址
├─────────────────────┤
│        ...          │
├─────────────────────┤
│   堆 (Heap) ↑       │  动态分配（malloc）
├─────────────────────┤
│   BSS 段            │  未初始化全局变量
├─────────────────────┤
│   数据段 (.data)     │  初始化全局变量
├─────────────────────┤
│   只读数据 (.rodata) │  常量、字符串字面量
├─────────────────────┤
│   代码段 (.text)     │  机器指令
└─────────────────────┘
低地址
```

### 各段说明

| 段名 | 权限 | 内容 | 特点 |
|------|------|------|------|
| .text | r-x | 函数代码 | 只读、可执行 |
| .rodata | r-- | 常量 | 只读 |
| .data | rw- | 初始化全局变量 | 可读写 |
| .bss | rw- | 未初始化全局变量 | 自动清零 |
| heap | rw- | 动态分配 | 向上增长 |
| stack | rw- | 局部变量、调用栈 | 向下增长 |

### 栈帧结构

```
┌─────────────────────┐ ← 高地址
│   caller 的栈帧     │
├─────────────────────┤
│   参数 (如果有)     │
├─────────────────────┤
│   返回地址          │
├─────────────────────┤
│   saved %rbp        │ ← 当前 %rbp 指向这里
├─────────────────────┤
│   局部变量          │
├─────────────────────┤
│   ...               │ ← 当前 %rsp
└─────────────────────┘ ← 低地址（栈顶）
```

## 任务

### 任务 1: 识别内存段

**目标**: 确定不同变量所在的内存段

**步骤**:
1. 运行程序，查看输出
2. 在 GDB 中使用 `info proc mappings`
3. 对比各段的地址范围

**问题**:
- `main` 函数在哪个段？
- `global_initialized` 在哪个段？
- `global_uninitialized` 在哪个段？
- `heap_var` 指向哪个段？
- `const_value` 在哪个段？

### 任务 2: 验证栈的增长方向

**目标**: 确认栈向哪个方向增长

**步骤**:
1. 断点在 `show_stack_growth()`
2. 查看 `var1`, `var2`, `var3` 的地址
3. 比较地址大小

**问题**:
- `var2` 的地址比 `var1` 高还是低？
- 栈向什么方向增长？
- 为什么设计成这样？

### 任务 3: 分析栈帧

**目标**: 理解函数调用的栈帧创建

**步骤**:
1. 在 `func_level1`, `func_level2`, `func_level3` 上设置断点
2. 使用 `backtrace` 查看调用栈
3. 使用 `info frame` 查看栈帧详情
4. 比较各层局部变量的地址

**问题**:
- 三层函数调用后，栈顶在哪里？
- `local1`, `local2`, `local3` 的相对位置？
- 如何找到返回地址？
- 如何找到上一层的栈帧？

### 任务 4: 查看内存映射

**目标**: 掌握查看完整内存布局的方法

**步骤**:
1. 使用 `info proc mappings` (GDB)
2. 查看各段的起始地址、大小、权限
3. 找到代码段、堆、栈的位置

**问题**:
- 代码段的权限是什么？
- 堆和栈之间有多少空间？
- 为什么有多个内存区域？

## 关键概念

- **代码段**: 存储机器指令，只读可执行
- **数据段**: 初始化的全局变量
- **BSS段**: 未初始化的全局变量（自动清零）
- **堆**: 动态分配，向上增长
- **栈**: 自动变量，向下增长
- **栈帧**: 函数调用的活动记录
