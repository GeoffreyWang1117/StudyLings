# GDB/LLDB 学习系统 - 更新日志

## v2.0.0 - 2024-11-18

### 🎉 重大更新：新增三个高级专题

#### 新增 Level 10: 数据结构调试
全面覆盖常见数据结构在调试器中的表现和调试技巧。

**Exercise 1: 链表调试**
- 单链表、双链表、循环链表的调试
- 检测链表环（Floyd 算法）
- 验证双向指针一致性
- 自定义链表遍历命令
- Python Pretty Printer 实现
- 内存泄漏检测

**Exercise 2: 二叉树调试**
- 二叉搜索树结构验证
- 父子指针完整性检查
- 树的递归遍历（前序、中序、后序）
- 树结构可视化
- 平衡性检查

**Exercise 3: 哈希表调试**
- 哈希函数分析
- 冲突处理（链地址法）
- 哈希分布检查
- 桶内链表遍历
- 动态扩容调试

#### 新增 Level 11: 多级指针调试专题
深入解析一级、二级、三级指针，这是C语言最容易困惑的部分。

**Exercise 1: 一级、二级、三级指针**
- 完整的指针链内存布局
- 逐层解引用技巧
- 静态与动态分配的多级指针
- 通过不同层次修改值
- 内存地址链路图
- Watchpoint 在多级指针上的应用

**Exercise 2: 指针数组 vs 数组指针**
- `int *arr[]` vs `int (*arr)[]` 的本质区别
- `char **argv` 的内存结构解析
- 动态二维数组的两种实现
- 矩阵的指针访问
- sizeof 和指针运算的差异

**Exercise 3: 函数指针与回调**
- 函数指针的声明和使用
- 函数指针数组（跳转表）
- 回调函数机制
- typedef 简化函数指针声明
- 虚函数表原理（C++ vtable）

#### 新增 Level 12: 内存布局和对齐专题
理解编译器如何在内存中组织数据。

**Exercise 1: 结构体对齐**
- 自然对齐规则
- Padding 的产生和计算
- 结构体成员重排序优化
- `__attribute__((packed))` 的使用
- `ptype /o` 查看详细布局
- 跨平台对齐差异

**Exercise 2: Union 和位域**
- Union 的内存共享
- 大小端序的观察
- 位域的内存压缩
- 网络协议头的位域应用
- 位操作的调试技巧

**Exercise 3: 内存段和栈帧**
- 代码段、数据段、BSS段
- 栈的增长方向
- 栈帧布局（局部变量、参数、返回地址）
- 堆内存分配
- 内存映射查看
