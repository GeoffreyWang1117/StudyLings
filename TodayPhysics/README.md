# TodayPhysics 今日物理

> 一个类似 Rustlings 的交互式物理学编程学习工具

通过编写代码来学习物理学——从经典力学到量子场论，边学边练，即时反馈。

## 项目特色

- **完整课程体系**: 覆盖本科到研究生的物理学核心内容，共 100 道精心设计的练习题
- **双语教学**: 每道题目都有中英文对照的说明和注释
- **边学边练**: 每个物理概念都有配套的编程练习，动手实现加深理解
- **可视化呈现**: 丰富的物理现象可视化，直观理解抽象概念
- **自动验证**: 即时反馈你的答案是否正确，提供详细错误信息
- **监视模式**: 保存文件自动运行，实时查看结果

## 安装指南

### 系统要求

- Python 3.8 或更高版本
- pip 包管理器

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/yourusername/TodayPhysics.git
cd TodayPhysics

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 依赖库说明

| 库名 | 用途 |
|------|------|
| NumPy | 数值计算与数组操作 |
| SciPy | 科学计算（微分方程、优化、积分） |
| SymPy | 符号计算与解析求解 |
| Matplotlib | 数据可视化与绑图 |
| Plotly | 交互式图表（可选） |
| QuTiP | 量子力学模拟 |
| EinsteinPy | 广义相对论计算 |

## 使用方法

### 基本命令

```bash
# 查看所有练习及完成状态
python runner.py list

# 运行下一个未完成的练习
python runner.py next

# 运行指定练习
python runner.py run 01_vectors
python runner.py run 01_classical_mechanics/05_harmonic_oscillator

# 监视模式（保存文件自动运行）
python runner.py watch

# 获取当前练习的提示
python runner.py hint

# 查看学习进度统计
python runner.py progress

# 重置某个练习
python runner.py reset 01_vectors
```

### 完成练习的步骤

1. **运行 `python runner.py next`** 打开下一个待完成的练习
2. **阅读题目说明**：理解学习目标和物理概念
3. **查看 HINT**：了解相关的物理公式和思路
4. **填写 TODO 部分**：根据提示完成代码
5. **保存文件**：验证系统会自动检查你的答案
6. **删除 `# I AM NOT DONE`**：完成后删除这行标记
7. **查看可视化**：运行 `plot_xxx()` 函数生成图像

## 常见问题

**Q: 如何知道我的答案是否正确？**
A: 保存文件后，`verify()` 函数会自动运行并显示 ✓ 或 ❌

**Q: 可以跳过某些练习吗？**
A: 可以，使用 `python runner.py run <练习名>` 运行任意练习

**Q: 如何查看参考答案？**
A: 完成练习后可在 `solutions/` 目录查看（如果提供）

**Q: 可视化图片保存在哪里？**
A: 默认保存在当前目录，文件名在函数内指定
