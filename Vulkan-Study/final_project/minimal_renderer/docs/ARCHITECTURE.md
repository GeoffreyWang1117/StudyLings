# Minimal Vulkan Renderer 架构文档

## 项目概述

Minimal Vulkan Renderer 是一个从零开始构建的轻量实时图形渲染系统，完整实现了 Vulkan 渲染管线的关键组件。

## 关键组件

### 1. Instance & Device
- VkInstance: Vulkan 库与应用程序的连接
- VkPhysicalDevice: GPU 硬件抽象
- VkDevice: 逻辑设备，命令执行接口

### 2. Swap Chain
- 双缓冲/三缓冲图像队列
- 管理帧呈现和屏幕刷新同步

### 3. Render Pass
- 定义渲染操作的结构
- 管理附件和子通道

### 4. Graphics Pipeline
- 顶点输入、光栅化、着色器阶段
- 完全预编译的管线状态

### 5. Command Buffers
- 录制 GPU 命令
- 支持多线程命令生成

### 6. Synchronization
- Semaphores: GPU-GPU 同步
- Fences: CPU-GPU 同步

## 性能优化

1. **命令缓冲预录制**: 静态场景可以预录制命令
2. **流水线屏障**: 精确控制资源访问
3. **内存管理**: 使用暂存缓冲进行数据传输
4. **描述符集复用**: 减少描述符更新开销
